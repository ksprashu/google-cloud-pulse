# Project Features

This document provides a comprehensive overview of all major features in the project. For more detailed information, click the feature title to view the full PRD.

---

## Core Application

### [Frontend Application](./features/frontend.md)
The user-facing React application that displays Google Cloud product updates.

### [Backend Application](./features/backend.md)
The Node.js service that provides data to the frontend and manages data processing.

### [Shared Types](./features/shared-types.md)
A package for shared TypeScript types between the frontend and backend.

## Development & Operations

### [Scalable Folder Structure](./features/scalable-folder-structure.md)
The monorepo structure using pnpm workspaces to organize the codebase.

### [Backend and Frontend Refactor](./features/refactor-to-backend-frontend.md)
The initial refactoring to separate the frontend and backend concerns.

### [Comprehensive Testing Strategy](./features/comprehensive-testing-strategy.md)
The testing setup for the frontend (Vitest) and backend (Jest).

### [Comprehensive Logging](./features/comprehensive-logging.md)
The logging solution for the backend service using `winston`.

### [Comprehensive Static Analysis](./features/comprehensive-static-analysis.md)
The code quality and formatting setup using ESLint and Prettier.

### [Cloud Build Sync](./features/cloud-build-sync.md)
The CI/CD pipeline for automated building, testing, and deployment.
